# Cube Arcade

基岩版的開房連線與玩家社群平台，提供 Windows 和 Android 版；iPhone、iPad 可以把網站加入主畫面使用。

網站：<https://cubearcade.net>

## 下載

### Windows

### 👉 [點我下載最新版（CubeArcade-Setup.exe）](https://github.com/CreeperMaple/cubearcade-releases/releases/latest/download/CubeArcade-Setup.exe)

- 要下載的是 **`.exe` 檔**。如果你是從「Releases」頁面下載，請點 `CubeArcade-Setup-版本號.exe`，不要下載 `Source code`、`.blockmap` 或 `latest.yml`。
- 安裝過一次之後，程式會自動更新，不用再回來下載。

### Android

### 👉 [點我前往 Google Play](https://play.google.com/store/apps/details?id=org.cubearcade.app)

### 👉 [點我下載 APK（CubeArcade.apk）](https://github.com/CreeperMaple/cubearcade-releases/releases/latest/download/CubeArcade.apk)

- 建議從 Google Play 安裝；Google Play 無法安裝時再下載 APK。
- 需要 Android 10 以上的 64 位元手機。

## 安裝時跳出安全警告怎麼辦？

Cube Arcade 是個人開發的免費程式，目前還沒有購買程式碼簽章憑證，所以 Windows 可能會顯示警告。這是正常的，照下面的方式就能安裝。

**「Windows 已保護您的電腦」（藍色視窗）**
1. 點 **「其他資訊」**。
2. 點 **「仍要執行」**。

**瀏覽器說「這個檔案通常不會被下載」**
- Edge：把滑鼠移到下載項目上，點「⋯」→「保留」→「顯示更多」→「仍要保留」。
- Chrome：在下載清單點「保留」。

**防毒軟體把它當成病毒**
- 因為程式會在背景做網路連線，有時會被防毒軟體誤判。請只從這個頁面或官方網站下載。
- 遇到誤判可以寫信給 cubearcade.support@gmail.com，我們會向防毒軟體廠商回報。

## 支援

- 開房和加入房間支援 Windows 版和 Android 版的基岩版。
- iPhone、iPad 可以把網站加入主畫面使用，可以加入房間，但不能開房。
- 問題回報或下架申請：cubearcade.support@gmail.com
